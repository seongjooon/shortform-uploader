# 실제 계정 스모크 테스트

자동으로 실행하지 않는다. 개발자 앱과 권한이 준비된 뒤 사용자가 명시적으로 승인한
짧은 테스트 MP4로 수행한다. 계정 ID·토큰·세션 URL·콜백 URL은 결과 문서에 남기지 않는다.
현재 상태: **미실행 — 앱 등록·인증 정보·승인된 테스트 영상이 필요함**.

1. YouTube Data API, Instagram 앱 역할/권한, TikTok `video.upload` 승인을 확인한다.
2. 세 플랫폼 `auth` 후 설정의 계정 ID가 인증한 계정과 일치하는지 로컬에서 확인한다.
3. 3초짜리 세로 MP4로 `--dry-run`을 실행한다. 개인정보 없는 테스트 문구를 사용한다.
4. YouTube는 `private`로 업로드한다. 반환 URL과 Studio의 동영상을 확인한다.
   공개 게시가 필요하면 미검증 프로젝트 제한을 실제 계정에서 별도 확인한다.
5. Instagram에는 테스트 게시물이 공개될 수 있다. 테스트 계정을 사용하고 원한다면 앱에서 보관한다.
   게시 제한 조회·릴스 생성·영상 업로드·게시·permalink를 확인한다.
6. TikTok 앱 받은편지함 알림을 확인하고 CLI 캡션을 붙여넣어 직접 게시한다.
   이후 `status`로 전달 상태가 최종 게시 상태로 바뀌는지 확인한다.
7. 세 플랫폼을 선택한 단일 실행으로 플랫폼별 결과가 모두 저장되는지 확인한다.
8. 완료된 job에 `retry`를 실행해 영상이 추가 생성되지 않는지 확인한다.
9. 미확인 상태는 원격 확인부터 한다. 테스트를 위해 네트워크를 끊었다면 새 job으로 즉시 재업로드하지 않는다.

실행 후 날짜, 플랫폼별 통과/실패, 비밀값을 제거한 오류 코드, 수동 확인 결과만 기록한다.
Instagram에는 API의 private 업로드 옵션이 없으므로 전체를 private로 검증할 수는 없다.
